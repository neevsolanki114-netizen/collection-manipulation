# 🎓 Student Data Organizer

A simple **Python-based Student Data Organizer** that helps manage student records using Python dictionaries, lists, loops, and conditional statements. This project provides a menu-driven interface to add, display, update, and delete student information.

## 📌 Project Overview

The Student Data Organizer is a beginner-friendly Python project designed to practice basic programming concepts and collection manipulation. It stores student details such as ID, name, age, grade, subjects, and date of birth.

## ✨ Features

- **Add Student:** Add a new student with complete details.
- **Display All Students:** View the records of all students.
- **Update Student Information:** Update a student's age and subjects.
- **Delete Student:** Remove a student record using their ID.
- **Display Subjects Offered:** View the list of available subjects.
- **Exit:** Safely exit the program.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Data Structures:** Lists and Dictionaries
- **Concepts:** Loops, Conditional Statements, User Input, Searching, Adding, Updating, and Deleting Records

## 📂 Student Information

Each student record contains the following details:

| Field | Description |
|---|---|
| ID | Unique student identification number |
| Name | Student's name |
| Age | Student's age |
| Grade | Student's academic grade |
| Subjects | Subjects studied by the student |
| Date of Birth | Student's date of birth |

## 🚀 How to Run

1. Install Python on your computer.
2. Copy the project code into a Python file named `student_organizer.py`.
3. Open a terminal or command prompt in the project folder.
4. Run the following command:

   ```bash
   python student_organizer.py
   ```

5. Select an option from the menu and follow the instructions displayed on the screen.
